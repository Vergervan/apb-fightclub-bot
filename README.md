# APB Fight Club Bot

Telegram-бот для отслеживания онлайн-статуса районов в игре APB Reloaded по данным сайта GamersFirst.

## Что делает бот

Бот периодически опрашивает страницу статуса APB и уведомляет пользователей, когда значения районов в выбранном регионе меняются относительно заданного порога.

Основные функции:

- отслеживание статуса районов для регионов `EU` и `NA`;
- периодическая проверка данных по таймеру;
- отправка уведомлений в чат при изменении статуса по порогу;
- поддержка разных настроек для каждого чата;
- сохранение состояния между перезапусками.

## Как бот работает

1. Бот запрашивает страницу `https://www.gamersfirst.com/apb/status` с выбранным регионом.
2. Из HTML извлекаются значения для целевых районов.
3. Сравниваются текущие значения с предыдущими значениями и порогом.
4. Если статус изменился значимо, бот отправляет сообщение в Telegram.

Целевые районы:

- `EU`: `EU PGAsylum`, `EU PGCrate`
- `NA`: `US West PGAsylum`, `US West PGCrate`

## Команды бота

- `/start` — запустить отслеживание
- `/stop` — остановить отслеживание
- `/status` — показать текущее состояние выбранного региона
- `/region EU` — выбрать регион Europe
- `/region NA` — выбрать регион North America
- `/threshold 4` — установить порог предупреждения
- `/help` — показать список команд

## Настройки по умолчанию

- регион: `EU`
- интервал проверки: `60` секунд
- порог: `4`

## Переменные окружения

Бот читает токен Telegram из переменной окружения `TELEGRAM_TOKEN`.

Также поддерживается вариант с файлом:

- `TELEGRAM_TOKEN_FILE` — путь к файлу с токеном

## Запуск через Docker Compose

1. Создайте файл `telegram_token.txt` с токеном Telegram:

```bash
echo "YOUR_TELEGRAM_BOT_TOKEN" > telegram_token.txt
```

2. Запустите контейнер:

```bash
docker compose up -d --build
```

3. Для остановки:

```bash
docker compose down
```
